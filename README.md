# Chatbot
A beginner-friendly chatbot built using Python that responds to simple user questions, provides time-based greetings, and uses predefined responses.
# First  Chatbot 🤖

This is my first  project, created using Python.

It is a simple chatbot that:
- Greets the user according to the current time
- Accepts questions from the user
- Provides predefined responses
- Handles simple conversations
- Allows the user to exit by typing "by"

## Technologies Used

- Python
- datetime
- Dictionary
- Functions
- Loops
- Conditional statements

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or Command Prompt.
4. Run:

python firstProject.py

5. Enter your name and start chatting with the bot.
